About EcoVision AI

EcoVision AI is a smart plastic waste detection system that uses a trained YOLO deep-learning model to identify plastic waste from images. The system connects a responsive web interface with a Python Flask backend, AI detection model and SQLite database.


The goal is to demonstrate how Artificial Intelligence can support environmental awareness and help people identify plastic waste more efficiently.
